Votación Online (VOE)

Este proyecto fue desarrollado como parte de una práctica académica avanzada. Se trata de un sistema de votación online con patrón MVC implementado en PHP, integración de base de datos, registro de usuarios, autenticación y lógica de voto segura.

  • Desarrollado con PHP, MySQL, Bootstrap y JavaScript.
  • Funcionalidad de login y roles (usuario y administrador).
  • Vista para votaciones activas y resultados en tiempo real.
  • Interfaz responsive y moderna.
